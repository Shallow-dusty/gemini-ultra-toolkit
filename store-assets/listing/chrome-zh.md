## 详细描述

```
Primer++ for Gemini™ 是一款非官方、开源的 Google Gemini 网页版增强扩展，为 gemini.google.com 添加可选的本地组织、归档、复用和检索工作流。所有数据都在浏览器里处理；不需要 Primer++ 账号，不上传遥测，不连接产品后端，也不做云端同步。

═══════════════════════════════════════
功能模块
═══════════════════════════════════════

• 本地洞察 Insights — 按日期和模型保留设备内活动记录，展示连续天数、趋势和全年热力图。这些是本地观察值，不代表 Gemini 服务端剩余额度。

• 集合 Collections — 用分层集合整理对话引用，支持排序、颜色、置顶、批量移动、规则预览、安全智能规则、迁移和撤销。

• 归档与导出 Archive — 由你明确触发后捕获当前或选中对话的可见内容，保留记录结构，并导出 JSON / CSV / Markdown / TXT / HTML / DOCX；失败或空捕获会如实标记。

• 便携备份与恢复 Backup — 导出所选本地功能数据的版本化备份，执行校验、预览、去重、选择性恢复、失败回滚和中断续跑。

• 配方 Recipes — 保存可复用 prompt 和带参数模板，使用标签整理、渲染后插入输入框、分步加入队列，并导入 / 导出本地库。

• 消息队列 Queue — 在本地暂存 prompt，再由你明确开始、暂停、取消或重排；Gemini 工具模式活跃时会暂停，不会静默重试。

• 搜索与导航 Search — 检索你明确归档或导入的本地记录，筛选排序、跳转到对话定位点或生成锚定引用；不会偷偷索引隐藏对话。

• 注释 Annotations — 为重要对话保存本地笔记、置顶和引用，需要时由你明确插入上下文包。

• 偏好 Preferences — 选择可用的首选模型，调整主题、语言、布局、输入行为与快捷键，并检测快捷键冲突。

• 批量生命周期 Bulk — 多选对话后执行有确认、进度和暂停 / 取消边界的归档或删除流程。

• 能力健康 Capability Health — 显示集成当前是可用、Gemini 原生、不可用、降级、关闭，还是因前端变化注入失败。

每项可选功能都可独立开关。界面使用统一主题、双语组件、键盘交互和持久化偏好。Gemini 原生的 Notebooks、搜索、Usage Limits、Gems/Skills、Canvas、Deep Research 与 Spark 保持由官方提供，不重复实现。

═══════════════════════════════════════
隐私与数据
═══════════════════════════════════════

• 所有数据存放在你设备本地的 chrome.storage.local 中。
• 任何数据都不会上传 — 不传给开发者，不传给任何分析服务，不传给任何地方。
• 只有当你明确保存配方或加入 Message Queue 时，prompt 文本才会保存在本地。只有当你明确归档 / 导出、插入上下文包，或导入本地归档时，可见对话文本才会被读取；不会持续收集隐藏对话。已归档文本会留在本地，直到你删除。
• 唯一申请的 host 权限：https://gemini.google.com/*。
• 完整隐私政策：https://github.com/Shallow-dusty/primer-pp/blob/main/PRIVACY.md
```

## 权限说明（翻译版，提交时建议英文为主，此处仅参考）

### `storage`

```
仅在设备本地保存偏好设置与按账号隔离的数据：洞察、集合、明确创建或导入的归档、配方、排队的 prompt、注释、由本地归档生成的搜索记录、恢复进度、面板布局、语言 / 主题和功能启用状态。所有数据写入 chrome.storage.local，Primer++ 不会把它们传出设备。
```

### `contextMenus`

```
为扩展工具栏图标的右键菜单添加一个 "Reset Panel Position" 项，用户把悬浮面板拖出屏幕时可以一键复位。不向页面上下文菜单添加任何项。
```

### Host 权限：`https://gemini.google.com/*`

```
内容脚本只在 Google Gemini（https://gemini.google.com/*）上运行。它读取用于本地账号隔离的账号标签、当前模型和能力状态、侧边栏对话引用，以及已启用工作流所需的页面事件。只有当用户明确归档 / 导出或插入上下文包时，才读取可见对话内容。扩展未申请 <all_urls> 或其他 host 权限。
```

### 远程代码

```
否。扩展打包时已把所有 JavaScript 内嵌在 content.js 与 background.js 中。运行时不从任何远程源加载代码。不使用 eval、Function 构造器、innerHTML / insertAdjacentHTML 或 script 标签注入。
```
